# EGID | وسيط الخبراء الصناعي والتجاري — دليل الرفع والتشغيل (الإصدار النهائي)

## الجديد في هذا الإصدار
- تصميم EGID الكامل (اللغتان، ساعة الفترات، الحجز، التسويات، B2B) متصل بقاعدة بيانات حقيقية.
- واجهة بنمط تطبيقات الآيفون: شريط تبويب سفلي، ونوافذ تنزلق من الأسفل، وصفحة «المزيد»، وزر رجوع وسحب من الحافة، وإضافته للشاشة الرئيسية كتطبيق.
- كل صفحة مستقلة برابطها (#b2b ، #bookings ، #more ...).
- فلاتر محسّنة (بحث عربي ذكي، تخصص، فترة، ترتيب، إعادة ضبط).
- لوحة المالك داخل الموقع نفسه (لا يوجد admin.html بعد الآن) ولا تظهر إلا لحسابك.
- لا تُعرض أرقام الخبراء ولا بياناتهم البنكية للجمهور.

## الملفات
- site/: ارفعها إلى GitHub (index.html و logo.png و manifest.webmanifest و icon-180.png و icon-192.png و icon-512.png).
- sql/schema_v3.sql: شغّله في Supabase (مطلوب).
- sql/sample_experts.sql: اختياري، خبراء تجريبيون.
- sql/schema_all_v3.sql: لمن ينشئ مشروع Supabase جديدًا من الصفر (يغني عن الملفين السابقين).

## الخطوات (من الآيفون)

### 1) قاعدة البيانات (مرة واحدة، قبل أي شيء)
1. افتح مشروعك في supabase.com ← SQL Editor ← New query.
2. الصق كل محتوى sql/schema_v3.sql ← Run. رسالة «Success. No rows returned» تعني النجاح.
3. (اختياري) كرّر الأمر مع sql/sample_experts.sql لترى الموقع مليئًا بخبراء تجريبيين.
   إن كان مشروعك جديدًا تمامًا فاستخدم sql/schema_all_v3.sql وحده بدلًا من الاثنين.

### 2) رفع الموقع إلى GitHub
1. افتح مستودعك: github.com/ktg2f7f8f5-boop/EGID
2. Add file ← Upload files، واختر ملفات مجلد site كلها (6 ملفات).
3. اضغط Commit changes. تُستبدل الملفات القديمة بنفس الأسماء. (يمكنك حذف admin.html القديم.)
4. انتظر دقيقة أو دقيقتين ثم افتح https://ktg2f7f8f5-boop.github.io/EGID/
   إن ظهر الشكل القديم فأعد تحميل الصفحة أو افتحها بنافذة خاصة.

### 3) حساب المالك
1. في الموقع: المزيد ← تسجيل الدخول / إنشاء حساب ← أنشئ حسابًا ببريد Aly.Ghazal@icloud.com.
2. أكّد البريد من رسالة التأكيد (راجع الرسائل غير المرغوبة).
3. سجّل الدخول، وستظهر تبويبة «الإدارة» في الشريط السفلي، أو من المزيد ← لوحة الإدارة والمالية.

### 4) الإعداد الأول من لوحة الإدارة
- الدفع والتواصل: أرقام إنستا باي والمحفظة والواتساب والبريد، ويمكنك رفع شعار.
- النصوص: عدّل أي نص بالعربية أو الإنجليزية (اتركه فارغًا ليعود للأصل).
- التخصصات: أضف أو احذف.
- الخبراء: أضف خبراءك الحقيقيين، وفعّل «تم التحقق من الشهادات» بعد مراجعتها فقط. واحذف الخبراء التجريبيين.
- الفقرات والصفحات: فقرات الصفحة الرئيسية، و«من نحن»، و«الشروط والخصوصية».

### 5) إضافته للشاشة الرئيسية كتطبيق (آيفون)
في Safari: زر المشاركة ← إضافة إلى الشاشة الرئيسية. يفتح بملء الشاشة بأيقونة EGID.

### 6) اختبار قبل الإعلان
- أنشئ حساب عميل ببريد آخر، واحجز موعدًا، وتأكد أن الموعد المحجوز يُغلق للآخرين.
- من لوحة الإدارة: اعتماد الدفع (يطلب رابط Zoom/Meet) ثم التسوية.
- أرسل طلب B2B وطلب انضمام خبير واستفسارًا، وتأكد أنها تظهر في اللوحة.

## مشاكل شائعة
- خطأ عند الحجز: لم يُشغَّل schema_v3.sql بعد.
- لا يظهر الخبراء: لا خبراء مفعّلون بعد، أضفهم أو شغّل sample_experts.sql.
- لا تظهر تبويبة الإدارة: البريد غير مؤكد أو ليس Aly.Ghazal@icloud.com.
- لا تصل رسالة التأكيد: راجع الرسائل غير المرغوبة وتأكد من Site URL في Supabase.
- الشعار أو الأيقونات لا تظهر: تأكد من رفع الصور بجانب index.html.

## قبل الإطلاق التجاري
سجل تجاري وبطاقة ضريبية وفواتير للشركات، وعقد الخبير وشروط واسترجاع (محامٍ)، وحساب بنكي خاص بالنشاط، والتحقق الفعلي من شهادات كل خبير. وراجع نصوص التصميم التي تذكر «معتمد» و«رسمي» وعدّلها من لوحة النصوص إن لم تكن دقيقة قانونيًا.
